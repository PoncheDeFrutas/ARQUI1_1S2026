# ARQUI1_1S2026

Repositorio de la asignatura Arquitectura de Computadores y Ensambladores 1. El curso esta enfocado en sistemas IoT y en el lenguaje ensamblador, con secciones de trabajo en ARM64 y RISC-V. Se utiliza una Raspberry Pi (modelos 3, 4 o 5) como plataforma principal para el bloque IoT y para el flujo nativo ARM64.

Los sistemas IoT son clave para comprender como el software interactua con el hardware y el entorno fisico: sensores, actuadores, tiempos de respuesta y consumo energetico. El lenguaje ensamblador, por su parte, permite ver el funcionamiento interno del procesador, comprender registros, instrucciones y memoria, y optimizar o depurar a bajo nivel. Ambos enfoques se complementan para construir soluciones eficientes y entender la arquitectura de computadores desde la practica.

Incluye materiales, ejemplos y documentacion de apoyo, ademas de referencias a documentacion oficial para profundizar.

## Secciones principales

- [01_PYTHON](01_PYTHON/README.md)
  Contenido de Python para IoT con GPIO, documentacion y lecciones practicas.
- [02_ARM64](02_ARM64/README.md)
  Contenido de ensamblador ARMv8/AArch64, ruta formativa y laboratorio para IoT.
- [03_RISCV](03_RISCV/README.md)
  Contenido de ensamblador RISC-V 64 en Linux user-mode, con flujo cruzado, QEMU, GDB y lecciones progresivas.
