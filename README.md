# ARQUI1_1S2026

Repositorio de la asignatura Arquitectura de Computadores y Ensambladores 1. El curso está enfocado en sistemas IoT y en el lenguaje ensamblador ARMv8, por eso se utiliza una Raspberry Pi (modelos 3, 4 o 5) como plataforma principal.

Los sistemas IoT son clave para comprender cómo el software interactúa con el hardware y el entorno físico: sensores, actuadores, tiempos de respuesta y consumo energético. El lenguaje ensamblador, por su parte, permite ver el funcionamiento interno del procesador, comprender registros, instrucciones y memoria, y optimizar o depurar a bajo nivel. Ambos enfoques se complementan para construir soluciones eficientes y entender la arquitectura de computadores desde la práctica.

Incluye materiales, ejemplos y documentación de apoyo, además de referencias a documentación oficial para profundizar.
